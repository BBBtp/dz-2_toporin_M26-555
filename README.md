# Примитивная база данных

Учебное консольное приложение на Python 3.12. Схемы таблиц хранятся в
`db_meta.json`, а записи — в отдельных JSON-файлах каталога `data/`.
Поддерживаются целые числа, строки и булевы значения. Столбец `ID:int`
создаётся автоматически, поэтому указывать его в `insert` не нужно.

## Установка и запуск

```bash
poetry install
poetry run database
```

Также доступны `make install`, `make run`, `poetry run project` и запуск без
установки из корня проекта: `python3 -m src.primitive_db.main`.
Команды `project` и `database` ведут к одной точке входа: в разных частях
задания используются оба имени.

## Управление таблицами

```text
create_table users name:str age:int is_active:bool
list_tables
info users
drop_table users
```

`create_table` проверяет типы, имена и дубликаты столбцов. Удаление таблицы
требует подтверждения `y` и удаляет её файл данных.

## CRUD-операции

```text
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
delete from users where ID = 1
```

Строковые значения рекомендуется заключать в кавычки, особенно если они
содержат пробелы. `where` и `set` принимают одно условие/присваивание вида
`столбец = значение`. Все поля при вставке обязательны. `true` и `false`
преобразуются в булевы значения. Для удаления записей требуется подтверждение.
Команда `help` выводит справку, `exit` завершает работу.

Повторные одинаковые выборки кэшируются замыканием; ключ кэша включает
содержимое таблицы, поэтому изменение данных не отдаёт устаревшую выборку.
Декораторы централизуют обработку ошибок, подтверждение опасных действий и
измерение времени вставки/выборки.

## Проверка и сборка

```bash
make test
make lint
make build
make publish        # только --dry-run, ничего не загружает в PyPI
```

После сборки пакет можно установить командой `make package-install`.
В проекте предусмотрены зависимости `prompt` и `prettytable`. При запуске
из исходников без них используется стандартный ввод и простой текстовый
вывод таблиц; установленный пакет использует обе библиотеки.
